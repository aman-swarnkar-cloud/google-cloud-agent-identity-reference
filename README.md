# Google Cloud Agent Identity Reference

A practical reference for separating **user identity**, **delegated user authority**, and **agent identity** in enterprise Agentic AI solutions built on Google Cloud and the Gemini Enterprise Agent Platform.

## Purpose

Enterprise AI agents can interact with cloud resources, tools, APIs, and external systems under different security contexts. This repository explores how those identities should remain distinct and how access can be designed using least-privilege principles.

## Scope

This reference will focus on:

- Gemini Enterprise Agent Platform
- Agent Identity
- Google Cloud IAM
- Delegated user authority where supported
- Agent Gateway and governed tool access
- Identity and authorization decision patterns
- Reference architectures and sequence diagrams

## Approach

The repository is based on publicly available Google Cloud documentation and general cloud security principles. It is intended as a generic technical reference, not as a representation of any specific customer implementation.
